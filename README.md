# Loan Calculator

## Description

A simple Python loan calculator that calculates loan interest, total interest, total loan amount, and monthly payment based on the loan amount and repayment period.

## How It Works

The program asks the user for:

- Loan amount
- Number of months to pay

It then calculates:

- Monthly interest
- Total interest
- Total loan
- Monthly payment

## Features

- Accepts decimal loan amounts
- Calculates interest at a fixed 10% rate
- Calculates total interest and total loan amount
- Calculates monthly payment

## Technologies

- Python

## Purpose

This project was built to practice Python fundamentals, including user input, variables, arithmetic operations, data types, and basic program structure.
